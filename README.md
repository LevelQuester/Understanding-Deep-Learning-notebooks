# Understanding Deep Learning - Notebooks

This repository contains my solutions, class notes, and worked-through Jupyter notebooks based on the book **"Understanding Deep Learning"** by Simon J.D. Prince.

It includes practical assignments, neural network implementations, and experiments for each chapter of the book, ranging from the basics of machine learning to modern deep learning architectures like CNNs, ResNets, and Transformers.

## Repository Structure

The repository provides materials for the following chapters:

- **Chapter 2:** Supervised Learning
- **Chapter 3:** Shallow Neural Networks
- **Chapter 4:** Deep Neural Networks
- **Chapter 5:** Loss Functions
- **Chapter 6:** Fitting Models
- **Chapter 7:** Gradients and Initialization
- **Chapter 8:** Measuring Performance
- **Chapter 9:** Regularization
- **Chapter 10:** Convolutional Neural Networks
- **Chapter 11:** Residual Networks
- **Chapter 12:** Transformers

## How to Use

Each folder corresponds to a specific chapter from the book and contains `.ipynb` files with code, plots, and comments. To run them locally, you will need:
- Python 3.x
- Jupyter Notebook or JupyterLab
- Standard Data Science libraries (NumPy, Matplotlib) and PyTorch / TensorFlow (depending on the assignments).
